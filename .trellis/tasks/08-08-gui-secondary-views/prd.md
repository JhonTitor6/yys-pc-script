# GUI 工作流、历史与设置重构

## Goal

在统一应用骨架和运行工作台完成后，重构工作流、历史和设置页面，完善非阻塞反馈，并通过全量集成验收交付一致的现代化 GUI。

## Background

- 父任务：`08-08-gui-modern-workbench`；依赖 `08-08-gui-shell-theme` 和 `08-08-gui-run-workbench`。
- 当前工作流编辑器是字段较多的长模态框，历史使用卡片列表并把详情追加在列表下方，设置页主要是说明文本。
- 父任务已决定不增加通知抽屉，短操作使用 Toast，运行状态由顶部状态栏和运行页承担。

## Requirements

- 工作流列表与编辑器改为主工作区内的独立子视图；保留现有 CRUD、立即运行、启用/停用、调度和步骤失败策略。
- 编辑器提供返回、保存和明确的未保存修改状态；返回、一级导航切换及关闭编辑视图都执行 dirty 离开保护。
- 长编辑过程不使用持续遮挡页面的模态框；保存失败在对应区域说明原因并保留草稿。
- 历史默认使用紧凑表格，列出任务、状态、开始时间、耗时、来源、错误码，支持状态、任务和时间筛选。
- 800×600 下隐藏次要列并以两行摘要保留核心信息，不产生横向滚动。
- 历史详情使用独立子视图；返回时恢复筛选、页码和滚动位置。
- 历史详情展示配置、步骤时间线、证据、日志和后端允许的恢复操作；manual 关联重试继续创建新 run。
- 设置页只展示真实有效能力；至少提供与顶部共用状态的浅色/深色选择和持久化说明，不放置无效未来开关。
- 短操作使用可访问 Toast；不新增通知抽屉。

## Acceptance Criteria

- [ ] S3-AC1：工作流列表可进入新建/编辑子视图，保存、返回、立即运行、启用/停用和删除保持可用。
- [ ] S3-AC2：工作流草稿修改后，从返回、一级导航或关闭编辑视图离开都会提示；取消离开保留草稿，保存成功清除 dirty。
- [ ] S3-AC3：历史表格可按状态、任务和时间筛选并分页；800×600 下核心信息完整且无横向滚动。
- [ ] S3-AC4：历史详情展示运行摘要、配置、步骤、错误、日志、快照和证据；返回后恢复列表筛选、页码和滚动位置。
- [ ] S3-AC5：manual 详情的“重新识别并重试”继续调用既有 retry 接口并创建关联新 run，非法状态不显示该操作。
- [ ] S3-AC6：顶部主题快捷按钮与设置页外观选项始终同步；首次默认浅色，切换后重启保持。
- [ ] S3-AC7：Toast 不阻塞、不夺焦点并可被辅助技术感知；运行中跨页仍通过顶部状态栏返回运行页或紧急停止，没有重复通知抽屉。
- [ ] S3-AC8：现有工作流/历史/设置相关后端契约、托盘行为和运行控制没有回归。
- [ ] S3-AC9：浅色/深色及 800×600、900×650、1280×720 的完整四页流程通过真实 Electron 视觉验收。
- [ ] S3-AC10：GUI Node 检查、受影响 UI 后端测试、`git diff --check` 和父任务最终验收通过。

## Out of Scope

- 不新增通知持久化、复杂分析图表、OCR/ROI 工具页、插件系统或无后端支持的设置项。
- 不扩展工作流调度语义、历史数据模型和恢复策略。
- 不修改游戏脚本。
