# GUI资源、截图与狭间配置增强

## Goal

让非开发者通过桌面 GUI 管理生产识别图片、采集并裁剪游戏画面，以及配置狭间暗域副将和精英伤害阈值；用户资源与截图不依赖安装目录，重新安装后仍可使用。

## Scope and Child Mapping

- `08-15-gui-image-resource-persistence`：生产图片清单、用户覆盖、运行时解析、重装保留与资源管理 GUI。
- `08-15-gui-game-screenshot`：空闲/运行中截图、异常自动取证、Cropper.js 框选裁剪、截图库及资源替换联动。
- `08-15-abyss-deputy-elite-threshold-config`：副将与精英伤害阈值的 schema、默认值、运行时注入与回归测试。
- 父任务只负责跨子任务契约和最终集成验收，不承载独立生产代码。

## Requirements

- R1：资源管理覆盖当前安装包内全部生产识别图片，不硬编码图片数量；运行中允许原子替换，后续匹配读取新版本。
- R2：截图支持手动和自动触发、完整帧永久保存、矩形裁剪及确认后替换资源；运行中截图不得刷新缓存、抢焦点、发送输入或改变运行状态。
- R3：狭间暗域分别配置 `commander_damage_limit` 与 `elite_damage_limit`，只影响对应敌人类型并保持旧配置兼容。
- R4：资源覆盖、截图文件和截图元数据统一保存到 Electron `userData` 下，安装目录只保存内置默认资源。
- R5：新增工具操作不得改变既有脚本启动、配置保存、`available_actions`、未覆盖图片和无新字段旧配置的行为。

## Acceptance Criteria

- [ ] AC1：三个子任务分别通过自己的 PRD 验收，并能独立开始、检查和归档。
- [ ] AC2：从“运行异常自动截图 → 证据页查看 → 框选裁剪 → 确认替换资源 → 后续识别读取新图”的跨子任务链路可完整验证。
- [ ] AC3：使用安装包完成升级或重新安装后，资源覆盖、完整截图及裁剪截图仍可读取；内置资源随安装包更新且未被直接修改。
- [ ] AC4：截图、替换前后 run 状态、阶段、`available_actions`、窗口焦点和输入记录符合各子任务契约；狭间新字段不改变其他脚本配置。
- [ ] AC5：真实打包产物可启动后端、读取资源清单和截图库，并通过 `/api/scripts` 返回两个新增狭间字段。

## Out of Scope

- 本规划阶段不修改生产代码，不启动父任务或子任务实现。
- 不顺带处理挑战次数接线、OCR 性能、图片相似度调参或无关 GUI 重构。
