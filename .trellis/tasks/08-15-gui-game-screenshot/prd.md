# GUI游戏截图

## Goal

用户可从 GUI 手动采集游戏客户区，也能在脚本异常或连续无法识别场景时自动留下完整画面；截图可永久查看、矩形裁剪、保存或用于替换识别资源。

## Background

- `WindowsEnvironment.capture_screen()` 已有 `print_window` 与 `foreground` 模式；硬件加速画面应采用激活游戏后的前台客户区捕获，并校验前台句柄与客户区尺寸。
- 运行脚本的 `ImageFinder.screenshot_cache` 每轮更新；现有 `RunManager._read_script_screenshot()` 会主动刷新缓存，需要拆出只复制缓存的无副作用路径。
- `RunManager` 已在启动异常、入口准备失败、脚本异常和停止超时时记录证据；`EventBaseScript` 每轮都知道是否识别到注册事件，可用于连续未知计数。
- 现有 GUI 已有非阻塞通知、运行“证据”页和日志页；自动截图不需要新增运行控制动作。
- 项目前端是 Electron 加原生 HTML/CSS/JS，无构建器；矩形选区采用本地固定版本 Cropper.js，不使用 CDN。

## Requirements

- R1：GUI 在运行工作台提供独立截图入口，在资源条目提供“截图并替换”入口；截图不是 `available_actions` 中的运行控制动作。
- R2：没有活动运行时，手动截图按“恢复并激活游戏 → 有界等待约 0.5 秒 → 验证前台窗口 → 捕获完整客户区 → 无论成功失败均恢复 GUI”执行，不得捕获其他桌面区域。
- R3：存在活动运行时，手动和自动截图只取得脚本最近有效缓存的独立副本，不激活窗口、不调用缓存更新方法、不暂停/恢复运行、不发送输入；缓存缺失或无效时明确失败且不回退前台捕获。
- R4：每次手动或自动捕获先永久保存完整帧；手动捕获随后打开 Cropper.js 预览，支持创建、移动、缩放矩形选区，按原图像素输出裁剪结果。
- R5：空、越界或零尺寸选区不得保存；预览缩放、窗口尺寸和高 DPI 不得改变裁剪像素结果；空图、零字节或近似纯色完整帧按捕获失败处理。
- R6：裁剪结果可另存为永久截图；仅从资源条目进入时显示“替换当前资源”，替换前再次显示目标并确认，写入复用资源子任务的校验和原子替换。
- R7：确定性启动/入口/脚本/停止超时异常自动保存证据；此外连续三轮未识别到任何注册事件时自动保存一次，同一连续未知过程不重复，识别到任一已知事件后清零并重新布防，脚本始终继续运行。
- R8：自动截图静默保存，只发送非阻塞通知并标记证据页，不打开模态框或切换页面；手动截图成功后立即打开可关闭的预览裁剪界面。
- R9：完整帧和裁剪图保存在 `userData` 的持久化截图库，附带截图 ID、时间、触发原因、尺寸以及可用的 run/script/stage 关联；应用不自动清理，只允许用户删除明确选中的截图。
- R10：删除截图不删除运行记录、日志或已复制到资源覆盖目录的图片；关联证据保留“文件已删除/不可用”状态，不影响其他截图。

## Acceptance Criteria

- [ ] AC1：空闲时可从 GUI 捕获并预览游戏完整客户区；未找到窗口、激活失败、前台校验失败、尺寸异常或近似纯色时明确失败且不生成截图记录。
- [ ] AC2：运行中手动截图前后的 run 状态、阶段、`available_actions`、动作记录和窗口焦点完全一致，返回独立缓存副本；缓存不可用时脚本继续运行。
- [ ] AC3：第 1、2 个连续未知帧不保存，第 3 个保存一次，第 4 个及后续连续未知帧不重复；恢复识别后再次连续未知三轮可保存下一张，整个过程不停止脚本。
- [ ] AC4：启动异常、入口准备失败、脚本异常和停止超时通过同一持久化截图服务留证，读取缓存时不主动刷新或抢焦点。
- [ ] AC5：手动和自动捕获均先保留完整帧；取消裁剪不删除完整帧，自动捕获只通知和更新证据，不改变页面、焦点或未保存表单。
- [ ] AC6：矩形选区在缩放预览、800×600 窗口及高 DPI 下按原图坐标输出，尺寸与选区一致；非法选区不产生文件。
- [ ] AC7：“保存截图”只新增裁剪图；“替换当前资源”只改变确认目标，取消或失败不改变覆盖，删除源截图后已生效覆盖仍可读取。
- [ ] AC8：截图列表可预览完整帧和裁剪图，并显示触发原因及运行关联；从关联运行可查看已有日志和状态快照，无需复制日志文件。
- [ ] AC9：应用重启、升级或重新安装后截图和元数据仍可读取，长时间未访问也不会自动删除；用户删除单项不影响其他截图或运行记录。
- [ ] AC10：Cropper.js 从本地固定版本加载；断网环境和真实打包产物均可打开裁剪器并完成保存。

## Out of Scope

- 不录制视频，不监听键盘鼠标，不自动识别裁剪目标，不保存连续帧历史。
- 不为截图增加运行暂停、前台抢焦点回退、自动清理或独立日志打包。
