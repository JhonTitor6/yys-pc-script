# GUI图片资源替换与持久化

## Goal

用户无需修改安装目录或源码，即可在 GUI 中定位并替换所有生产识别图片；应用升级或重新安装后继续使用当前用户版本。

## Background

- 仓库共有 218 个 BMP/PNG。排除 `test`、`tests`、`debug`、`logs`、`example`、`recordings` 后，Git 基线有 97 个生产资源；当前工作树因未提交的 `yys/common_challenge/images/gained_reward.bmp` 有 98 个。清单必须动态生成，不能硬编码数量。
- `win_util.image.to_project_path()` 当前只解析源码根或 PyInstaller `_MEIPASS`；`SceneManager` 还会把目录扫描结果保存为项目根下的绝对文件路径，因此相对路径和项目内绝对文件都必须支持覆盖解析。
- `ImageFinder` 不缓存模板图片，每次匹配都会重新读取解析后的文件；原子替换成功后，运行中的后续匹配可直接读取新版本。
- Electron 已使用 `app.getPath('userData')`，但后端尚未接收该目录；安装包当前把后端相对 `config/` 写到安装资源目录附近。
- GUI 已有“设置”一级页面，本任务在该页面增加资源管理区，不增加一级导航。

## Requirements

- R1：以安装包内 `yys/**/*.bmp|png` 为来源动态生成生产资源清单，共用一套排除目录规则；资源 ID 使用规范化 POSIX 相对路径。
- R2：资源清单按脚本/公共目录分组，显示当前生效缩略图、文件名、相对路径和“内置/已覆盖”状态，支持按文件名或路径搜索；不维护逐图片中文别名。
- R3：Electron 启动后端时传入专用 `userData` 根；用户覆盖按原相对路径保存在该根下，目录仍从内置树枚举，文件读取优先选择有效覆盖。
- R4：相对项目图片和位于项目根内的绝对图片文件均应用覆盖；外部绝对路径保持原行为，项目图片目录仍指向内置目录以保证部分覆盖不会遮蔽其他文件。
- R5：替换只接受清单内资源 ID 和可解码 BMP/PNG 内容，拒绝路径穿越、未知 ID、空文件、解压炸弹和无效图片；调用方不能指定服务器目标路径。
- R6：替换先在目标目录写入并校验临时文件，再用同目录原子替换当前覆盖；运行中不暂停、不切换焦点、不发送输入，已开始的一次匹配可使用旧完整版本，后续匹配使用新完整版本。
- R7：每项只保留当前用户版本和安装包内置默认版本；再次替换前明确确认，成功后覆盖旧用户版本；“恢复默认”只删除该项覆盖，不维护多版本历史。
- R8：从资源条目可选择本地文件，或进入截图裁剪流程；两种入口共用相同校验、原子写入、持久化和确认契约。
- R9：重新安装不得删除或重写 `userData` 中的有效覆盖；安装包新增资源自动进入清单，删除的内置资源不再暴露，也不得通过旧 ID 写入。
- R10：未覆盖资源、非项目绝对路径、现有匹配阈值与调用参数的行为保持不变。

## Acceptance Criteria

- [ ] AC1：测试根据安装树动态计算预期清单；Git 基线 97 个资源全部可管理，当前工作树存在第 98 个资源时也自动纳入，排除目录中的图片均不出现。
- [ ] AC2：相对路径图片、`SceneManager` 注册的项目内绝对图片均优先读取对应覆盖；外部绝对路径和没有覆盖的资源仍读取原文件。
- [ ] AC3：GUI 可按组、缩略图和路径定位任一生产资源，搜索结果正确显示当前覆盖状态，不需要同步维护中文别名表。
- [ ] AC4：本地文件替换与截图裁剪替换均只改变确认的资源；取消、校验失败或原子替换失败时保留原有效版本。
- [ ] AC5：运行中替换前后的 run 状态、阶段、`available_actions`、焦点和输入记录不变；并发读取只能得到替换前或替换后的完整图片。
- [ ] AC6：恢复默认后立即读取当前安装版本的内置图；其他覆盖、永久截图及运行证据不受影响。
- [ ] AC7：路径穿越、未知/已删除资源 ID、不支持格式、空文件和不可解码内容均返回明确错误，且不会在覆盖目录留下可生效的临时文件。
- [ ] AC8：升级或重新安装后，原有有效覆盖继续生效；新安装包新增资源使用内置默认图，已移除资源不会被旧覆盖重新注入清单。
- [ ] AC9：真实打包后端收到 Electron 提供的持久化根，资源清单与覆盖读取均不落到安装目录。

## Out of Scope

- 不提供标注、滤镜、相似度调参、批量导入、逐图中文别名或多版本自定义历史。
- 不修改内置图片文件本身，不把用户覆盖或现有未提交图片写入 Git。
