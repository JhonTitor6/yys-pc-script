# 地域鬼王单次挑战

## 目标与已确认事实

- 用户要求基于手动录制创建独立地域鬼王脚本，并确认「按录制流程，挑战指定鬼王一次后停止」；允许 luna-worker 实现。
- 有效录制：`recordings/regional_demon_boss/20260907T130329Z-9e74a0d8`，110438 ms，1136×640，3 FPS，16 个操作，正常结束且无丢帧。上一段 5 秒误录不作为实现证据。
- 流程：庭院 → 式神录预设 → 地域鬼王分组/悬赏阵容 → 庭院 → 探索 → 地域鬼王地图 → 一次拖拽 → 丹霞山/山童 → 挑战 → 自动准备和战斗 → 两层结算 → 详情页/地图。
- `frames/000012-before.png` 显示当前难度设置；录制没有修改难度。
- `frames/000005-after.png` 显示无确认弹窗直接提示「全队正在使用预设御魂和阴阳术」与「替换阴阳师契灵成功」。现有 `yys/common/lineup.py` 仅接受确认弹窗及装备御魂成功分支，需兼容已验证的新分支。

## 需求和验收

1. 独立 `regional_demon_boss` 脚本在脚本列表可见，首版目标固定为录制中的丹霞山/山童；默认应用地域鬼王/悬赏预设，沿用游戏已有难度，不更改御魂或阵容配置数据本身。
2. 从庭院启动完成录制流程。地图导航最多使用已录制的一次拖拽，每次操作后重新识别；目标缺失/目标不符/未知页面不得盲点或随意扩大搜索。
3. 挑战只发出一次；进入准备/战斗后零输入，直到确认结算。结果多帧重复时仅计数一次，清理奖励后停止，不发起第二次挑战。失败也只结束本次，不自动重试。
4. 预设切换结果不明确、入口失败必须明确失败，不把正常函数返回当作业务完成；过程响应停止与暂停，接入既有保险丝与观察入口。
5. 共享预设的旧行为原子保持：分组只在分组区域精确匹配；阵容只在选中分组列表精确匹配；同行应用图标验证；旧确认分支只点击明确的确定且等待装备御魂成功；预先存在弹窗拒绝；旧提示不得被当成本次成功；未知结果不重复应用。
6. 新增无确认成功分支必须来自本次应用后的新鲜画面，完整「全队正在使用预设御魂和阴阳术」提示与契灵成功提示一起验证；仅有契灵成功不算全队预设成功。
7. 使用脱敏真实帧验证新模板及负样本；离线回放覆盖入口、单次挑战、战斗零输入、重复结算、未知目标与停止。新增脚本/CLI 不改变旧通用挑战、结界突破和狭间行为。

## 范围外与验证边界

- 不做每日多鬼王轮巡、分数刷取、星级调整、自动重试、任意地图全局搜索。
- 不改录制器性能，不删除误录，不提交或归档任务。
- 此轮先实现和离线验证；未获得新一轮真实执行授权前不发送游戏输入，不把离线回放写成实机验证。
