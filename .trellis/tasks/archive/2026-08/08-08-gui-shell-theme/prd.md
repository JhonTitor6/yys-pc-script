# GUI 视觉基础与应用框架

## Goal

在不改变现有页面业务与运行契约的前提下，建立浅色默认双主题、统一设计令牌、可折叠导航、全局顶部状态栏和适配现有 Electron 窗口的应用骨架，为后续运行页及其他页面重构提供稳定基础。

## Background

- 父任务：`08-08-gui-modern-workbench`。
- 当前应用是四栏深色布局，默认窗口 900×650、最小窗口 800×600。
- 当前导航使用字体符号，主题只有深色；CSS 已有局部变量但不是完整语义令牌。
- `08-08-universal-entry-recovery` 已完成并归档；当前 GUI 以提交 `6421685` 的阶段、继续等待和关联重试行为为回归基线。

## Requirements

- 首次启动默认浅色，允许切换深色并持久化；页面加载时避免主题闪烁。
- 两个主题共享同一语义令牌结构，并分别满足文字、边界、焦点与状态颜色对比度。
- 使用系统字体、4/8 间距、统一圆角/阴影/图标/动效；阴阳师气质只使用少量朱红、暖金和印章式几何点缀。
- 一级导航仅保留运行、工作流、历史、设置，使用本地 SVG 图标与文字，可由用户折叠；800×600 自动使用图标模式。
- 阶段 2 完成内容合并前，原进度视图通过运行页内的临时“查看详细进度”入口继续可达，不作为独立一级导航。
- 全局顶部状态栏展示当前页面、后端连接、当前运行摘要、查看运行、条件性紧急停止和主题快捷切换。
- 紧急停止仅在 current run 的 `available_actions` 包含 `stop` 时出现，并复用现有控制函数。
- 这一阶段不重写任务卡片、运行内容、工作流编辑器和历史展示；现有页面及所有操作仍必须可达。

## Acceptance Criteria

- [ ] S1-AC1：无保存主题时首次启动为浅色；顶部按钮可切换深色并在应用重启后保持，没有明显主题闪烁。
- [ ] S1-AC2：浅色和深色均使用语义令牌，正文达到 WCAG AA，状态不只靠颜色，键盘焦点清晰，减少动效生效。
- [ ] S1-AC3：900×650 默认显示图标和文字导航；800×600 自动折叠，用户仍可手动切换且页面上下文不丢失。
- [ ] S1-AC4：顶部状态栏在所有一级页面显示连接和 current run 摘要；仅当后端允许 `stop` 时显示紧急停止，并可返回运行页。
- [ ] S1-AC5：原进度入口不再作为一级导航出现；阶段 2 完成内容合并前，运行页内的“查看详细进度”兼容入口可以打开原进度视图，不造成能力丢失。
- [ ] S1-AC6：现有脚本启动、暂停、恢复、停止、继续等待、重试、跳过、人工接管、工作流、历史和设置行为没有回归。
- [ ] S1-AC7：800×600、900×650、1280×720 下无非预期横向滚动、固定元素遮挡或不可达控制。
- [ ] S1-AC8：Node 语法检查、现有 GUI Node 测试和受影响 UI 后端测试通过。

## Out of Scope

- 不在本阶段重构运行工作台内容、工作流编辑方式、历史表格和详情。
- 不新增前端依赖、网络字体、主题素材包、自动跟随系统主题或第三种主题。
- 不修改运行时状态、API、数据库或游戏脚本。
