# 按名称应用队伍预设

在继承 `YYSBaseScript` 的脚本中显式调用：

```python
self.switch_lineup("寮活动", "通用")
```

狭间暗域脚本从 Home 启动时已经内置调用该方法：成功应用后通过已有返回模板回到 Home，再继续原有的狭间入口导航；从狭间选择页、暗域区域、敌人选择页或战斗中恢复时不会重复切换。

也可以独立复用，注入自己的截图、输入环境及已有 OCR 实例：

```python
from yys.common.lineup import LineupSwitcher

LineupSwitcher(env, ocr=ocr).switch("寮活动", "通用")
```

成功返回 `None`，失败抛出异常。默认总时限 60 秒，每个方向最多滚动 30 次；可以通过 `timeout_seconds`、`max_scrolls` 调整。基础脚本入口响应既有暂停、停止和运行保险丝，独立调用可传 `checkpoint` 接入调用方取消逻辑。

## 行为与边界

- 允许从已验证的庭院、式神录、队伍预设页启动，自动打开需要的面板；其他页面或预先存在的确认弹窗不猜点。
- `group_name` 只查右侧分组，`lineup_name` 只查该分组内的预设。OCR 去除空白后全名匹配，不以“通用”匹配“pve通用”。同屏多个同名目标会报错，请为同一分组的预设设置唯一名称。
- 目标不在当前视口时，先向上查找到边界，再向下查找，每次滚轮后重新截图；滚动上限、无进展或总超时均有明确失败结果。
- 名称和应用按钮必须处于同一行，分组必须高亮。应用前会等待上一轮的旧成功提示（包括直接成功双提示）消失；应用后可以沿用“即将为全队式神更换预设御魂”确认流程，点击明确的“确定”后等待新的“装备御魂成功”，也可以在同一张新鲜画面中同时看到“全队正在使用预设御魂和阴阳术”与“替换阴阳师契灵成功”直接成功；仅看到其中一条不会返回成功。
- 此功能重现录制中的应用预设动作，包含游戏随预设执行的御魂/契灵替换；并不代表操作了副本出战槽位。完成后停留在预设页，返回庭院或进入副本由调用脚本负责。
- 确认后没有捕获成功提示时，结果可能已经生效。不要自动重跑应用，应先核对当前状态。
- 坐标依据 1136×640 真实帧按客户区尺寸换算；不同布局必须补充截图验证。识别失败不降阈值或盲点。
