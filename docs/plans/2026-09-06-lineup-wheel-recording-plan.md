# 阵容切换流程的滚轮录制准备

## 用户目标与本次范围

用户需要录制切换阵容的流程，按分组名和阵容名进行 OCR 查找，两个列表通过鼠标滚轮滚动。本次先补齐录制事件，供后续从真实画面生成切换脚本。阵容入口、名称样本、成功提示和列表边界判据等待实际录制，暂不猜测坐标或实现切换。

## 验收标准

- 保存目标游戏前台客户区内的竖向滚轮事件：客户区坐标、时间、有符号原始 delta、操作前后截图；正数向上，负数向下，保留小于 120 的高精度增量。
- 窗口外、其他前台应用和注入的滚轮输入不进入真人操作记录；钩子只监听并继续传递消息。
- 监听失败明确终止并保留失败元数据，不能显示录制成功。
- 新录制使用 v2，读取仍兼容 v1；候选材料保留滚动量，旧场景回放器不得静默把滚轮变成点击。
- 此前已有的行为不得改变：左/右点击坐标不变，拖拽保留起终点，键盘事件不变，F12 仍停止且不记为普通按键，旧录制和旧夹具仍可读取。
- 新增可选 on_wheel 只影响启用它的录制器；受保护脚本仅使用原有监听参数，不安装滚轮钩子。record_mouse 原有参数继续只表示原有动作，新增可选 wheel_delta 只用于 wheel 动作。

## 实施与验证

复用现有输入线程、截图队列和 JSONL，使用 ctypes 调用 Windows 原生低级鼠标钩子，不新增依赖。先验证合约、持久化、候选导出及监听生命周期，再以本机原生钩子启动/卸载验证 ABI，最后由用户在真实游戏中滚轮录制验证。

API 依据：[LowLevelMouseProc](https://learn.microsoft.com/en-us/windows/win32/winmsg/lowlevelmouseproc)、[MSLLHOOKSTRUCT](https://learn.microsoft.com/en-us/windows/win32/api/winuser/ns-winuser-msllhookstruct)。

## 当前进度

滚轮监听、v2 事件与 v1 兼容读取、关键帧候选导出、失败传递已实现；本机原生钩子启动与卸载检查通过。后续已完成通用阵容切换实现与下述真实主流程回放。未提交 Git。

## 通用功能验收与兼容约束

- 提供独立 `LineupSwitcher(env, ocr=...).switch(group_name, lineup_name)` 和基础脚本 `self.switch_lineup(group_name, lineup_name)` 入口，不绑定某个业务脚本，不自动改变已有业务流程。
- group_name 只用于右侧分组列表；lineup_name 只用于该分组内的预设名称。去除空白后全名匹配，不使用子串或相似文字替代；同屏多个同名目标明确失败。
- 允许从录制已证明的庭院、式神录或预设页开始；未知画面、启动时已有确认弹窗均零输入失败。模板和 OCR 均使用实际截图范围；坐标按当前客户区尺寸换算。
- 先查当前可见区域；未找到时向上寻找边界，再向下扫描。每次滚动后重新截图识别，保留视口重叠；无进展、达到边界、滚动次数/总时限耗尽时明确失败，不无限滚动。
- 点分组后必须确认对应分组高亮。应用按钮必须与已识别的目标名称处于同一行；不使用固定第几行。
- 只确认本次明确触发的“即将为全队式神更换预设御魂”弹窗；确认前不接受旧成功提示；确认后识别到新“装备御魂成功”才返回成功。超时结果不确定时不得自动重试应用。
- 所有输入经过 GameEnvironment；新增 wheel 走原有 GuardedEnvironment 动作预算和观察模式。未实现 wheel 的旧环境仍可实例化，调用 wheel 时明确报不支持。
- 此前已有行为不得改变：点击/拖拽/按键的环境路由、坐标语义、观察模式、动作上限、业务计数、入口准备和截图默认模式。新增基础脚本方法只在显式调用时执行，响应脚本暂停/停止。
- 验证包含真实截图的 OCR、模板和已录制主流程回放，以及缺失/重名/滚动查找/取消/确认超时的合约测试；滚轮实机效果需要补充样本，不能用 Mock 结果替代。

## 实施结果与剩余验证

- 公共环境增加非抽象 wheel 方法、Windows 消息实现和 GuardedEnvironment 路由，旧环境仍可实例化。
- `yys/common/lineup.py` 实现通用服务；基础脚本新增显式调用方法；`docs/lineup-switch.md` 记录调用方式和应用结果不明时的处理要求。
- 主流程回放使用真实 OCR 和五个实帧模板，严格按录制的五次点击到达成功；确认遮罩后的底层控件不得被当作当前可操作界面。
- 117 项相关回归通过，覆盖录制、环境路由、动作预算、基础脚本、入口准备与阵容功能。新增代码可编译。
- 当前游戏只读截图未出现式神录入口或预设页，公共识别器正确拒绝将其识别为预设页；本轮未进行真实切换或滚轮输入。
- 原始录制没有滚轮事件，滚动幅度、长列表边界、其他名称及其他分辨率的实机效果尚未验证。
- 狭间暗域 `Main.on_run()` 已在 Home 分支显式调用 `switch_lineup("寮活动", "通用")`，确认回到 Home 后才继续入口；其他启动场景保持零阵容输入。
