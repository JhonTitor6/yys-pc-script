# GUI 现代化视觉原型

这是一个只用于视觉评审的 Electron 原型，不代表生产实现：不连接真实 API、不启动后端、不改变运行逻辑。

## 启动

在仓库根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\prototype\gui-modernization\run.ps1
```

也可以直接打开 `prototype/gui-modernization/index.html`。

## 当前方向

- A「稳重工作台」：当前选定的后续基线，左侧配置、右侧执行，强调长期使用的确定性。

原型身份写在窗口标题中，不覆盖工作区；三种窗口尺寸预览和停止按钮演示放在“设置”页面。

运行页采用左侧配置、右侧执行的固定工作区：脚本选择和参数配置都在左侧，执行状态、进度、详细进度和旧版业务占位在右侧；运行中左侧配置只读，停止后恢复编辑。窗口外层不滚动，配置区与执行区各自按内容滚动。配置包含内存模拟的通用战斗次数、失败策略、人工接管、截图证据，以及按脚本切换的御魂、探索和狭间暗域字段；选择狭间暗域时会展示 `boss_damage_limit`、伤害策略、目标暗域和队长模式。
